# Бухгалтеру

- В отчёте по каждой работе есть цена, сколько уже выплачено и сколько осталось оплатить.
- В сумму выплат входят только деньги, которые ушли к дате отчёта. Возвраты вычтены, очередь на оплату не учтена.
- Платёж с номером работы отнесён к ней. Общий платёж зачтён по принятым работам, начиная с самой ранней.
- Нераспределённые деньги уже выплачены подрядчику. По ним ещё нужно уточнить, к каким работам их отнести.
- По договору отдельно показан остаток от подписанной суммы и остаток по работам. Если суммы расходятся, разница указана в отчёте.
- Подтвердите, как разносить общие авансы, считать ли материалы частью оплаты работы и что делать с выплатами по отменённым работам.
- По договору D-1 проверьте, уменьшилась ли сумма договора после отмены работы W-13.
